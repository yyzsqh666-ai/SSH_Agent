# SSH_Agent

本科物理科研学习项目：复现一维 Su–Schrieffer–Heeger（SSH）模型，并记录 AI 辅助科研流程中的计算、验证和人工参与。

## 背景与导师任务

项目负责人为大二物理专业学生，按照导师要求探索 SSH 模型与轻量化科研智能体。当前任务是理解模型、完成可复现数值计算，并评估 AI 辅助流程的可靠性。导师姓名、通信及原始任务材料不纳入仓库。

## 研究目标与真实进展

截至 2026-10-24，已完成文献入门整理、体能带、拓扑绕数、指定终止方式的有限开放链边界态，以及六种链长的能级劈裂比较。已执行的测试共 **56 项通过**，包括原有 16 项能带测试和 40 项拓扑及开放链测试。

| 计算 | 参数与实际结果 |
| --- | --- |
| 体能带 | `(t1,t2)=(1.5,0.5)、(0.5,1.5)、(1,1)`；完整带隙为 2、2、容差内 0 |
| 绕数 | 按本项目约定得到 0、1、临界点不定义 |
| 开放链 | 20 晶胞、40 格点；前两组分别检出 0、2 个满足能量及局域性判据的近零端态 |

尚未计算 Zak 相位，未开展无序、一般扰动或不同边界终止方式的研究。当前是已知模型的基准复现，没有证据证明智能体自主发现了新的物理结果，也没有成本或对照实验支持对智能体能力的量化结论。

## 模型与计算方法

采用无相互作用、无在位势、双亚格点最近邻厄米模型，晶胞长度 `a=1`。`t1` 为胞内跃迁，`t2` 为胞间跃迁，体计算使用正实跃迁：

$$
H(k)=\begin{pmatrix}0&q(k)\\q(k)^*&0\end{pmatrix},\qquad q(k)=t_1+t_2e^{-ik}.
$$

能带由 `numpy.linalg.eigh` 数值对角化，并与独立解析式

$$
E_\pm(k)=\pm\sqrt{t_1^2+t_2^2+2t_1t_2\cos k}
$$

对照；正实跃迁的完整带隙为 `2|t1-t2|`。默认能带网格包含区边界，共 1001 点；最大能谱绝对误差约 `2.58e-15`，低于 `1e-12` 的绝对容差。

绕数默认使用 2001 个动量点。固定 `k` 从 `-π` 增至 `π`，定义 `ν=-Δarg(q)/(2π)`；通常复平面绕数为 `w_q=-ν`。闭隙时不定义绕数；近临界或网格不足时返回未分辨状态。开放链基底为 `(A1,B1,...,AN,BN)`，切断边界 `t2` 键，两端为 `A1、BN`。近零端态同时满足能量与端部概率判据，有限链杂化本征态可能同时分布于两端。

详见[理论笔记](notes/ssh_theory.md)、[假设与约定](notes/ssh_topology_assumptions.md)及[理论预期](notes/ssh_topology_expectations.md)。

## 环境与运行

已验证环境为 Windows x64、Python 3.13.14，NumPy 2.5.4、SciPy 1.18.1、Matplotlib 3.11.2、pytest 9.1.1。完整版本快照见 `requirements-lock.txt`；其他系统或全新环境尚未独立验收。

在已安装 Python 3.13 的新项目副本中，用 PowerShell 执行：

```powershell
py -3.13 -m venv .venv
& '.\.venv\Scripts\python.exe' -m pip install -r requirements-lock.txt
& '.\.venv\Scripts\python.exe' -m pip check
```

若使用当前已有且可用的 `.venv`，直接运行下列命令，不需要重建环境。若未安装 `py` 启动器，可用实际 Python 3.13 解释器的路径替代第一条命令。核心计算不要求安装 GPD 或配置 API Key。

```powershell
# 两种计算分别生成新的时间戳结果目录
& '.\.venv\Scripts\python.exe' -B -m src.ssh_bands
& '.\.venv\Scripts\python.exe' -B -m src.ssh_topology

# 执行全部测试
& '.\.venv\Scripts\python.exe' -B -m pytest -q -p no:cacheprovider tests
```

拓扑脚本支持 `--num-k`、`--num-cells`；两种计算均支持 `--output-dir`，并拒绝覆盖已有目录。默认参数为已验证基准；更短的链可能无法满足既定近零判据。不要把 pytest 的 `--basetemp` 指向需要保留的目录。
