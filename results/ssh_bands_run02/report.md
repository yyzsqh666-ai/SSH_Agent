# SSH 能带计算与实际验证报告

运行日期：2026-10-17（Asia/Shanghai）；原始 UTC 时间见 summary.json。

## 模型与方法

- 标准一维、双亚格点、最近邻、无在位势 SSH 模型；晶胞长度 a=1，跃迁参数为正实数。
- 使用用户指定的 Bloch 哈密顿量；上右元为 t1+t2 exp(-ik)，下左元为其共轭。
- NumPy linspace 生成 1001 点，覆盖 [-π,π]，包括两个区边界。
- 每个动量点的两个本征值由 numpy.linalg.eigh 对矩阵独立求解，未用解析能量代替数值求解。
- 另用解析平方根公式对照；数值完整能隙从 min(E_upper)-max(E_lower) 得到，与 2|t1-t2| 比较。
- 绝对容差 1e-12、相对容差 0。这里的区边界包含实际最小隙位置，适用于本轮正实跃迁。
- Python 3.13.14，NumPy 2.5.4，Matplotlib 3.11.2；依赖完整快照见 ../../requirements-lock.txt。
