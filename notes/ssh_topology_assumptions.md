# 本轮物理假设与符号约定

日期：2026-10-24，Asia/Shanghai。这里仅规定模型和数值判据；理论预期见 `ssh_topology_expectations.md`，实际结果见 `../results/ssh_topology_run02/report.md`。

1. 沿用现有项目：一维、无相互作用、无自旋单块、每晶胞 A/B 各一个轨道、最近邻实跃迁；没有在位势、同亚格点跃迁、无序或驱动。晶胞长度 a=1，能量单位为输入跃迁单位。半填充时占据负能带。
2. t1 为胞内 A_n—B_n 键，t2 为 B_n—A_(n+1) 键。傅里叶约定是 a_n=N^(-1/2) Σ_k exp(ikn)a_k，b_n 同理，不加入胞内轨道位置相位。
3. 体基底固定为 (A,B)，动量从 -π 递增到 +π。严格复用 `src/ssh_bands.py` 的矩阵：

   $$H(k)=\begin{pmatrix}0&q(k)\\q(k)^*&0\end{pmatrix},\qquad q(k)=t_1+t_2e^{-ik}.$$

   等价地 d_x=t1+t2 cos k，d_y=t2 sin k，q=d_x-i d_y。手征算符 Γ=σ_z，ΓHΓ=-H。
4. 通常复平面逆时针绕数 w_q=Δarg(q)/(2π)。沿用既有理论笔记 (T9) 的 SSH 绕数 ν=Δarg(q*)/(2π)=-w_q。因此非平庸相的 q 顺时针绕行，w_q=-1、ν=+1。符号取决于基底、晶胞和动量方向，不能混用。
5. 开链有 N 个完整晶胞、2N 个格点，基底 (A1,B1,...,AN,BN)，端点 A1 和 BN。保留 N 条 t1 键、N-1 条 t2 键；没有 BN—A1 的周期闭合键。这个终止方式切断 t2 键，是体边对应解释的前提。

$$H_{\mathrm{OBC}}=\sum_{n=1}^{N}t_1(|A_n\rangle\langle B_n|+\mathrm{h.c.})
+\sum_{n=1}^{N-1}t_2(|A_{n+1}\rangle\langle B_n|+\mathrm{h.c.}).$$

数值选择单独列出，不能误认为物理定律：

| 项目 | 本轮取值 |
| --- | --- |
| 绕数参数 | (1.5,0.5)、(0.5,1.5)、(1,1) |
| 动量网格 | 2001 点，包含 [-π,π] 两端点；对 2000 个区间求相位增量 |
| 主开放链 | N=20，共 40 格点；前两组有隙参数 |
| 尺寸比较 | N=4、8、12、16、20、24，固定 (0.5,1.5) |
| 端部概率窗口 | 左、右各 3 个晶胞，不重叠 |
| 近零边界态经验判据 | 同时要求 abs(E) < 0.01 abs(t1-t2)、两端窗口概率之和 ≥0.9 |
| 线性代数检查 | 绝对容差 1e-12×max(1,t1+t2)；测试中的标准单位对照为 1e-12 |
| 小隙保护 | 若 abs(t1-t2) ≤ 1e-12(t1+t2)，拒绝给出数值整数；严格相等另标 gap_closed |
| 相位采样保护 | 要求 Δk_max t2/abs(t1-t2) < π/2，否则标 grid_unresolved，建议加密网格 |

严格相等时是物理上的绕数不定义；不相等但未通过数值保护时只表示本算法未分辨，不能据此宣称真实能隙已经关闭。上述相位步长界来自 |∂k arg q|≤|q'|/|q|≤t2/|t1-t2|，是这个圆形轨迹的保守充分条件。

绕数函数保留旧核心的严格正实跃迁输入范围。开链函数另外接受零跃迁以检验完全二聚化极限，未改变旧核心的输入范围。近零/端部阈值仅服务于本轮参数的分类，不能普遍判定所有短链或接近临界的链。

本轮只新增轻量 NumPy/Matplotlib 模块及 pytest 测试，使用已有依赖；没有实现 Zak 相位，没有调用多智能体或引入其他框架。
