# 本轮理论预期（与测量结果分开）

日期：2026-10-24。以下由固定模型推导，数值对照记录在 `../results/ssh_topology_run02/report.md`。

## 绕数

由 q=t1+t2 exp(-ik)，轨迹是圆心 (t1,0)、半径 t2 的圆，随 k 增大顺时针走一周。原点在圆外时 w_q=0，原点在圆内时 w_q=-1。按本项目 ν=-w_q 的定义：

$$\nu=\begin{cases}0,&t_1>t_2>0,\\1,&t_2>t_1>0.\end{cases}$$

可独立掌握的公式是

$$\nu=-\frac{1}{2\pi}\Delta\arg q
=\frac{i}{2\pi}\int_{-\pi}^{\pi}\frac{\partial_k q}{q}\,dk
=\frac{1}{2\pi}\int_{-\pi}^{\pi}
\frac{d_x\partial_k d_y-d_y\partial_k d_x}{d_x^2+d_y^2}\,dk.$$

连续相位要沿整条闭合轨迹跟踪，不能直接相减两个主值相位。实现按相邻点计算

$$w_q^{\mathrm{num}}=\frac{1}{2\pi}\sum_{j=0}^{M-2}
\mathrm{Arg}\!\left(\frac{q_{j+1}}{|q_{j+1}|}\frac{q_j^*}{|q_j|}\right),\quad\nu^{\mathrm{num}}=-w_q^{\mathrm{num}}.$$

这里 Arg 取主值，前提是网格足够细，不会漏掉相位转动。先检查能隙与网格，再求和，再检查与整数的距离；不是根据 t1/t2 的大小直接返回预期整数。

$$E_\pm=\pm|q|,\qquad E_g=2\min_k|q|=2|t_1-t_2|.$$

在 t1=t2>0 时 q(±π)=0，轨迹穿过原点、相位无定义、体隙关闭。不能把浮点残差当成小隙，也不能把可能得到的半整数或任意展开相位当作绝缘相绕数。接近临界但仍有隙时绕数理论上存在，只是可能需要更高精度和更密的网格。

## 开链与有限尺寸

对左端零能解取 B 亚格点振幅为零，B_n 方程给出

$$t_1\psi_{A,n}+t_2\psi_{A,n+1}=0,
\qquad\psi_{A,n+1}=-r\psi_{A,n},\quad r=\frac{t_1}{t_2}.$$

当 r<1，半无限链的左端态可归一化，振幅 ∝(-r)^(n-1)，概率 ∝r^[2(n-1)]；右端对应 B 亚格点。振幅局域长度 ξ=1/ln(t2/t1)，单位为晶胞。r>1 时这个终止方式没有可归一化的端部零模。临界点 ξ 发散。

半无限链归一化系数为 √(1-r²)。将左右端态截断到 N 胞并分别归一化，系数 C_N=√[(1-r²)/(1-r^(2N))]。它们只在对面的边界留下薛定谔方程残差；在两态子空间中的耦合绝对值为

$$|\langle L|H|R\rangle|=
t_2\frac{1-r^2}{1-r^{2N}}r^N.$$

因此当 N 远大于 ξ 时，完整有限链的低能量**近似**为

$$E_\pm\simeq\pm t_2\frac{1-r^2}{1-r^{2N}}r^N,\qquad
\Delta E=E_+-E_-\simeq 2t_2\frac{1-r^2}{1-r^{2N}}r^N.$$

这是端态重叠近似，不是有限 N 的精确能谱。对于严格正 t1，平衡 A/B 数目的有限链通常没有精确零能态；可从按亚格点重排后的非对角块行列式 t1^N≠0 看出 H 可逆。足够长时劈裂可能小于双精度误差，此时输出“零”不能证明精确零能。

反演对称有限链的两个可分辨本征态通常是左右端态的近似对称/反对称组合，两者各自在**两端**都有概率峰。它们的概率分布可几乎完全重合，区别在相对振幅符号。线性组合可以局域到单端，但劈裂非零时这种组合不是严格能量本征态。不能强迫数值本征求解器给出“一个只在左、一个只在右”。

独立测试基准还包括：t2=0 为 N 个胞内二聚体，能量各有 N 个 ±t1；t1=0 为 N-1 个胞间二聚体及两个悬空端点；t1=t2=t 的 2N 格点开链解析能谱为 E_m=2t cos[mπ/(2N+1)]，m=1,...,2N。最后一种有限偶数链没有严格零能级，尽管无限体体系无隙。
